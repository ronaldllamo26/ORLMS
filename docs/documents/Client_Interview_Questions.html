Ordinance and Resolution Lifecycle Management System (ORLMS)
Pinakamahalagang Requirements Validation Questions
Sangguniang Panlungsod, City of San Jose del Monte, Bulacan
Gabay para sa Magtatanong: Ito ang 5 pinaka-kritikal na tanong na kailangang masagot ng SP Secretariat o Legislative Officers upang makumpleto ang disenyo at workflow ng ating system.
[ ]

Q1: Kailan po binibigyan ng permanenteng Ordinance/Resolution Number ang isang panukala?

Pagka-file pa lang po ba bilang Draft (e.g., system-generated temporary number muna), o kapag fully signed and enacted na ni Mayor (kung kailan ilalagay ang official format tuloy-tuloy gaya ng 2024-971-02)?

Bakit tinatanong: Para maitakda kung kailan mag-o-auto-generate ang permanenteng tracking number sa database (sa umpisa ba ng drafting o pagkatapos ng final approval).
[ ]

Q2: Mag-lo-log in ba si Mayor at si Vice Mayor sa system para pumirma o mag-veto?

May hiwalay ba silang portal para mag-approve/veto sa system, o ang Secretariat lamang ang mag-e-encode ng naging desisyon nila pagkatapos nilang pirmahan ang hard copy?

Bakit tinatanong: Upang malaman kung kailangan nating gumawa ng hiwalay na user interface/dashboard para sa Mayor's Office at Office of the Vice Mayor, o sapat na ang Secretariat access.
[ ]

Q3: Sa pag-record ng Session Voting, kailangan ba nating itala ang boto ng bawat Councilor?

Kailangan ba ng nominal voting record (halimbawa: Councilor A = Yes, Councilor B = No), o sapat na po na i-input ang kabuuang bilang ng boto (e.g., Yes = 10, No = 2, Abstain = 1)?

Bakit tinatanong: Para maiwasan ang paggawa ng kumplikadong grid ng mga pangalan kung ang kailangan lamang sa archives ay ang kabuuang bilang ng boto.
[ ]

Q4: Kapag higit sa isang komite ang sumusuri (Joint Committee), paano ang endorsement flow?

Kailangan ba ng hiwalay na approval o endorsement mula sa bawat Chair ng mga komiteng kasangkot sa system, o sapat na ang isang pinagsamang Committee Report na i-encode ng staff?

Bakit tinatanong: Upang maayos ang logic ng transition status mula sa "Under Committee Review" patungong "Calendar for Second Reading".
[ ]

Q5: Ano-ano ang mga mandatory parts ng dokumento na dapat suriin ng ating AI Validation engine?

Ano ang mga standard clauses na hindi pwedeng mawala sa inyong draft (e.g., Title, Whereas Clauses, Enacting Clause, Separability Clause, Penalty/Sanction Clause, Effectivity Clause)?

Bakit tinatanong: Upang mai-configure nang maayos ang system prompt ng ating Llama Model (AI Validator) para maging tumpak ang pag-check sa mga kulang na bahagi ng draft.
